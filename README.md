# Solar System Voyager

**日本語** | [English](README.en.md) | [変更履歴](CHANGELOG.md)

太陽・惑星・主要衛星・準惑星・小惑星・彗星・探査機と、太陽から 10 光年ほどまでの恒星とその惑星を **実寸・実距離** で配置した 3D 宇宙飛行シミュレータです。
天体の位置は PC の時刻 (UTC) から計算し、等倍ではリアルタイムに公転・自転します。

- 描画エンジン: [raylib 5.5](https://www.raylib.com/)（OpenGL 3.3）
- 対応: Linux (gcc) / Windows (MinGW-w64)

## はじめての方へ

最初の起動時に、操作と見どころの短い案内（4 ページ）が出ます（Enter / タップで次へ、Esc で閉じる）。あとから見る時は H キーの操作説明を開いてください。

## ブラウザ版

インストールせずにブラウザで試せます: **https://hubstacksea.github.io/Solar-System-Simulator/**

- WebGL2 が使えるブラウザ（Chrome / Edge / Firefox / Safari の最近の版）で動きます。起動に要る約 8 MB だけを先に読み込み、惑星・衛星の地図、小惑星の形、月の地図、地球の雲と季節、小惑星帯など（約 25 MB）は遊びながら裏で読み込みます。届くまでは手続きで描いた表面で表示し、画面左下に「地図などを読み込み中（残り N）」と出ます
- 音楽は入っていません（効果音は鳴ります）。日本語は同梱のフォント（Noto Sans JP）で表示します
- 画面をクリックするとマウスで機首を操作できます（Esc で解除）。設定やブックマークはブラウザに保存されます
- スマホ・タブレットでは画面にボタンが出ます: ドラッグで機首の向き、右の「加速」「減速」「停止」、左の「ターゲット」「ワープ」「自動操縦」、上の「ツアー」「イベント」「全体図」「設定」「説明」「共有」、下のエンジン欄をタップで切り替え。画質は最初「低」になり、縦の画面が小さい時は縦 720 ピクセル相当で描いて縮めて表示します
- 描画が重い場合は F9 で画質を下げてください
- スマホや Retina などの高解像度の画面では、画面の倍率に合わせて細かく描きます（縦 1440 画素まで）。画質「低」では 3D の画素数は抑えたまま、文字と計器だけを細かく描きます
- **F2（タッチ操作では「共有」）で、今の場面のリンクをコピー**します（日時・場所・向き・ターゲット・時間倍率。アドレス欄も同じリンクになります）。リンクを開くとその場面から始まります。PC 版で F2 を押すとブラウザ版へのリンクがコピーされます
- **表示の言語は URL の `lang=ja` / `lang=en` で指定**できます（例: `https://hubstacksea.github.io/Solar-System-Simulator/?lang=en`。共有リンクの後ろに `&lang=en` を付けても使えます）。指定がなければ、J や設定で選んだ言語（初めての時は日本語）になります。URL での指定は保存されません
- ブラウザ版のページを開いた回数を [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) で数えています。Cookie は使わず、個人を特定する情報や操作の内容は送りません。PC 版・macOS 版は何も送りません

## macOS 版

[リリース](https://github.com/hubstacksea/Solar-System-Simulator/releases) の `SolarSystemVoyager-<版>-macos.zip`（macOS 11 以降、Apple Silicon / Intel 両対応）を展開し、`SolarSystemVoyager.app` を「アプリケーション」などに移して起動します。

- Apple の公証を受けていないため、最初の起動では「開発元を確認できない」と表示されます。**アプリを右クリック（Control+クリック）→「開く」→「開く」**で起動してください。macOS 15 以降でこの方法が出ない場合は、一度起動を試した後に **システム設定 →「プライバシーとセキュリティ」→「このまま開く」**を押します
- それでも開けない場合は、ターミナルで `xattr -dr com.apple.quarantine SolarSystemVoyager.app` を実行してから開いてください
- 設定とブックマークは `~/Library/Application Support/SolarSystemVoyager/solar_voyager.cfg` に保存します。日本語はヒラギノ角ゴシックで表示します。Retina の画面では細かい解像度で描きます
- 開発者のマシンでは動作を確認していません（GitHub Actions でのビルドのみ）。不具合があれば Issue で教えてください

## ビルド

CMake が raylib 5.5 のソースを自動取得して静的リンクします（初回のみネット接続が必要）。

### Linux

```sh
# Debian/Ubuntu の依存パッケージ
sudo apt install build-essential cmake libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/solar_voyager
```

### Windows (MSYS2 MinGW64)

```sh
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-cmake mingw-w64-x86_64-ninja
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/solar_voyager.exe
```

DLL 不要の単体 exe になります。コンソールを出したい場合は `-DSOLAR_CONSOLE=ON`。

### macOS

```sh
xcode-select --install   # コマンドライン ツール（clang）
cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64"
cmake --build build -j
open build/SolarSystemVoyager.app
```

### 自動ビルドとリリース（GitHub Actions）

`v2.37.8` のようなタグを push すると、`.github/workflows/release.yml` が Linux (.deb / .rpm)・Windows (.7z)・macOS (.zip)・ブラウザ版を作り、GitHub のリリースにパッケージを添付し、ブラウザ版を `gh-pages` ブランチへ置いて GitHub Pages で公開します。Linux 版は実際に起動してスクリーンショット（地球・火星・全体図・英語の設定画面）とログを撮り、実行結果の `screenshots-linux` に保存します（起動に失敗してもリリースは止めません）。macOS 版はデータを読めるかだけ確かめます（GitHub の Mac の仮想マシンは GPU が無く、ウィンドウを作れないため）。ブラウザ版もヘッドレスの Chrome で開き（`tools/web_smoke.py`、探査機の旅のリンクと、キー・クリック・ドラッグの操作も）、画面とコンソールの出力を `screenshots-web` に保存します。

```sh
git tag v2.37.8
git push origin master v2.37.8
```

### リリース前の確認

```sh
python3 tools/run_checks.py build/solar_voyager   # 画面のない環境では --no-display
```

データの読み込み、日食 9 件と NASA の日食表の照合、歴史のページの件数、ブラウザ版のフォントに画面に出る文字がすべて入っているか（足りなければ `tools/make_web_font.py` で作り直す）、全天体へのワープ（正面に着き、着いた後に動かない）、扁平な惑星の地表すれすれの光速飛行（表面が消えない）を確かめ、項目ごとに PASS / FAIL を出します（全部で 10 分ほど）。

### ブラウザ版（Emscripten）

```sh
emcmake cmake -B build-web -DCMAKE_BUILD_TYPE=Release   # 音楽も入れる場合は -DSOLAR_WEB_MUSIC=ON
cmake --build build-web -j
python3 -m http.server -d build-web 8000                 # http://localhost:8000/ で開く
```

`build-web/index.html`・`index.js`・`index.wasm`・`index.data` と `assets/` フォルダをそのまま Web サーバーに置けば動きます。データは実行ファイルに埋め込まず、起動に要るものは `index.data` にまとめ、大きな地図などは `assets/` から起動後に読み込みます（分け方は `CMakeLists.txt` の `WEB_PRELOAD` / `WEB_DEFERRED`）。シェーダは起動時に WebGL2 用（GLSL ES 3.00）に書き換えます。日本語フォント `web/NotoSansJP-subset.ttf` は `tools/make_web_font.py` で作ります。

### Linux から Windows 版をクロスビルド

```sh
cmake -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake -DCMAKE_BUILD_TYPE=Release
cmake --build build-win -j
```

## パッケージ作成

ビルド後、ビルドフォルダで `cpack` を実行します。

| 対象 | コマンド | 出力 |
|---|---|---|
| Windows (7-Zip) | `cd build-win && cpack` | `SolarSystemVoyager-<版>-win64.7z`（展開してそのまま使えるポータブル版） |
| Linux (.deb / .rpm) | `cd build && cpack` | `solar-voyager_<版>_amd64.deb` / `solar-voyager-<版>-1.x86_64.rpm` |
| macOS (.zip) | `cd build && cpack` | `SolarSystemVoyager-<版>-macos.zip`（地図などのデータは実行ファイルに埋め込まず `.app` の Resources に置き、Apple Silicon 用と Intel 用で共有。ad-hoc 署名） |

- Linux 版は `/usr/bin/solar_voyager` に入り、アプリメニュー（ゲーム）にアイコン付きで登録されます。`.rpm` の作成には `rpmbuild` が必要です
- 片方だけ作る場合: `cpack -G DEB` / `cpack -G RPM`
- バージョンは `CMakeLists.txt` の `project(... VERSION ...)`、`.deb` の Maintainer 欄は `-DSOLAR_PACKAGE_CONTACT="名前 <メール>"` で指定します
- exe のファイルアイコンとウィンドウのアイコンは `assets/icon.ico` / `assets/icon.png` です（`python3 tools/make_icon.py` で生成、Pillow が必要）

| マウス / 矢印キー | 機首の上下・左右 |
| A / D | ヨー、Q / E : ロール |
| W | 加速（離しても速度を維持） |
| S | 減速・後退 |
| X | 停止 |
| 1〜8 / ホイール | エンジン切替 |

## 自動操縦

ターゲットへ向けて「旋回 → 加速 → 巡航 → 減速」を自動で行い、ターゲット半径の約 3 倍の距離（ワープと同じ位置）に停止します。

- 減速は制動曲線（v = √(2·加速度·残り距離)）に沿うので、選択中エンジンの加速度で止まれる速度を超えません
- 時間倍率が大きくても到着点を行き過ぎません
- 経路上に天体がある場合は回り込みます。地表から地平線の下の目標へ向かう時は、接線方向へ上昇してから向かいます
- **Shift+T（エンジン自動選択）**: 時間倍率込みで実時間 約 60 秒以内に着く最も遅いエンジンを自動で選び、近づくにつれてシフトダウンします
- 手動操作（機首操作・W/S・X）やワープで解除されます。ターゲットを切り替えると新しいターゲットへ向かいます
- ターゲットは公転で動き続けるため、遅いエンジンでは惑星に追いつけないことがあります（地球の公転は約 30 km/s）

## 画面表示

- **速度計**（右下）: 現在のエンジンの最高速度を満点とするアナログメーター + デジタル表示
- **方位計**（上部中央）: 天体の近く（半径の 30 倍以内）では、その天体の自転軸を北とする方位・ピッチ・ロール。離れると黄経・黄緯で表示。黄色の▲はターゲットの方位
- **天体マーカー**: 太陽・全惑星の名前と表面までの距離。画面外の天体は画面端に矢印で表示。衛星は母天体の近くで表示。1 光年より遠い天体は恒星のほか、1 AU より遠い小惑星・探査機・人工衛星は表示しません（ターゲットはいつも表示）
- **空**: 地球と火星の大気の中では、太陽の高さに合わせて空の色が変わります（地球は青空・朝焼け・夕焼け・薄明、火星は黄褐色の昼と青白い夕方）。昼は星が隠れ、上空ほど暗くなって宇宙の黒に変わります。大気の中から見た地面や海は遠いほどかすんで空の色に溶け込み、地表・雲・海は太陽が低いほど赤い光で照らされます（宇宙から見ても、昼と夜の境目が赤みを帯びます）
- **近くの恒星**: 太陽から 10 光年ほどまでの 15 個（ケンタウルス座アルファ星 A・B、プロキシマ・ケンタウリ、バーナード星、ルーマン 16 A・B、WISE 0855−0714、ウォルフ 359、ラランド 21185、シリウス A・B、くじら座 BL 星・UV 星、ロス 154、エリダヌス座イプシロン星）と、17 光年ほどまでの主な 12 個（プロキオン A・B、はくちょう座 61 番星 A・B、ロス 128、くじら座タウ星、インディアン座イプシロン星 A、ティーガーデン星、エリダヌス座 40 番星 A・B・C、アルタイル）を、実際の位置・大きさ・表面温度の色で置いています。位置は Gaia DR3・ヒッパルコスなどの年周視差・固有運動・視線速度から等速直線運動で求め（年代とともに星の位置が変わります）、連星（ケンタウルス座アルファ星・シリウス・くじら座 BL 星と UV 星・ルーマン 16・プロキオン）は論文の軌道要素で重心のまわりを回ります。エリダヌス座 40 番星 B・C も Mason et al. (2017) の軌道で回ります。はくちょう座 61 番星 A・B も Shakht et al. (2017) の軌道（周期 664 年）で回ります（Hipparcos と Gaia の 2 つの時点の位置に合うことを確かめました）。アルタイルは速い自転でつぶれた形で、重力減光のため極が熱く白く明るく、赤道は暖かい色で暗く見えます。遠くからは星空の星と同じように明るさ（等級）に応じた点で見え、ケンタウルス座アルファ星からは太陽がカシオペヤ座の 0.5 等の星に見えます。これらの星は背景の星空から除いてあります。赤色矮星は表面に大きな黒点が高緯度まで広がり、フレア星（プロキシマ・ケンタウリ、くじら座 UV 星・BL 星、ウォルフ 359、ロス 154、エリダヌス座 40 番星 C）はときどき数分だけ最大で約 3 等明るくなって、表面の 1 か所が青白く光ります（頻度は実際より多めです）。白色矮星（シリウス B・プロキオン B・エリダヌス座 40 番星 B）は表面がなめらかで、強い青白い光がにじみます。褐色矮星（ルーマン 16 A・B、WISE 0855−0714）は、木星のような雲の帯と、明るさの変化の観測から分かっているまだらな雲で描きます。検索の「恒星」タブから選んでワープでき、約 1,900 AU より遠くへのワープは長く大きな恒星間ワープの演出になります（星空が前方へ集まって青くなり、渦を巻く光のトンネルを抜けます。残りの距離と、光の速さならかかる年数も出ます）。情報カードには、今見ている光が何年前に出たかも出ます。褐色矮星の質量・半径などには推定の値を含み、情報カードにそう表示します。自転軸の向きは分からないので、連星は軌道面に垂直、ほかは天の北極に向けています
- **太陽系の外の惑星**: 確認されている 17 個（プロキシマ・ケンタウリ b・d、バーナード星 b〜e、ラランド 21185 b・c、エリダヌス座イプシロン星 b、ロス 128 b、くじら座タウ星 g・h・f、インディアン座イプシロン星 A b、ティーガーデン星 b・c・d）が、NASA 系外惑星アーカイブの軌道要素（周期・離心率・近点通過の時刻）で恒星のまわりの今の位置を回り、その恒星の光で照らされます。視線速度だけで見つかった惑星は軌道の傾きが分からないため、傾斜角 60°（同じ星の惑星は同じ面）とし、質量は下限の値から、半径は質量から推定しています（エリダヌス座イプシロン星 b は位置天文で、インディアン座イプシロン星 A b は JWST の直接撮像で、傾きと真の質量が分かっています）。アーカイブに近点通過の時刻がない惑星（ロス 128 b、くじら座タウ星、ティーガーデン星の惑星）は、公転の位置も推定です。表面は分からないので、種類と温度で塗り分けています。公転周期 30 日未満の惑星は、いつも同じ面を恒星へ向けます。検索の「地上」からプロキシマ・ケンタウリ b の地上に立つと、赤い恒星が空の同じ位置に止まって見えます（地表は想像図で、パネルにそう表示します）。情報カードに平衡温度と推定の値を表示し、検索の「恒星系」タブから選べます。恒星を中心にした全体図には、水が液体でいられる範囲（ハビタブルゾーン。恒星の明るさから Kopparapu et al. 2013 の保守的な範囲の目安で求めた）を緑の帯で描き、中心からの距離は投影で縮めずに実際の距離で描きます
- **星空の年代**: 設定画面の「星空の年代」で、恒星と背景の星だけを 10 万年前〜10 万年後の位置に動かせます（惑星などの日時は変わりません。日付を変えられるのは惑星の計算が使える紀元前 3000 年〜西暦 2999 年）。背景の星はヒッパルコス星表（新しい整約）の固有運動で等速に動き（視線速度は入れていません）、北斗七星などの星座の形が崩れていきます。近くの恒星もその年代の位置になり、たとえば 3 万年ほど後にはケンタウルス座アルファ星が 3 光年あまりまで近づきます。変えている間は日時の横に表示されます
- **光速に近い速さでの見え方**: 光速エンジンで光速に近づくと、特殊相対論の光行差で星と天の川が前方へ集まり、前方はドップラー効果で青く明るく、後方は赤く暗くなります。惑星や太陽などの太陽系の天体も同じく前方へ寄り、すぐ近くの大きな惑星も形ごと歪んで見えます（シェーダで頂点ごとに光行差を掛け、色もドップラー効果で前方は青く、後方は赤く暗くなります。軌道の線は合わなくなるので消します）。強さは速さに比例するように見やすく割り当て、急停止しても約 1 秒かけてほどけます（超光速エンジンでは出ません）
- **探査機へのワープ**: 探査機や人工衛星へワープすると、機体の大きさに合わせた距離から、ズームした視野（右クリック・加速で元に戻る）で画面の中央に大きく見えます
- **超光速エンジン**: 8 番目のエンジンは、1 秒に 1 光年進む遊び用の架空のエンジンです。ワープせずに恒星の間を飛び、星空のずれが連続して変わっていく様子を見られます
- **星空**: 背景の星はヒッパルコス星表の実在の恒星（8 等級まで約 41,000 個）で、明るさと色（色指数）も実際どおり。その奥に天の川の淡い光（NASA の全天画像。ズームすると薄くなります）。アンドロメダ銀河・マゼラン雲・オリオン大星雲・イータカリーナ星雲・網状星雲・オメガ星団など、明るい星雲・銀河・星団 35 個も、公表されている位置・大きさ・向き・明るさでプログラムが描いた絵で表示します（写真ではありません。ズームすると形が分かり、かに星雲は 1054 年の超新星の後にだけ現れて広がります。設定の「天の川・星雲」で消せます）。C キーで 88 星座の星座線と、星座名・主な恒星（2.6 等より明るい約 100 個）の名前を表示します。星にはヒッパルコス星表（新しい整約）の年周視差からの距離があり、太陽から離れるとその場所から見た向きと明るさで描きます（ケンタウルス座アルファ星まで行くと、近い星ほど星座の中で位置がずれます）
- **前回の続きから**: 終了した時（とブラウザ版では 30 秒ごと）の場所・向き・ターゲットを保存し、次の起動でそこから始めます。設定画面で「場所だけ（日時は今）」（既定）・「場所と日時」・「オフ」を選べます。共有リンクで開いた時はリンクが優先です
- **ターゲット情報**（右上）: 距離、現在速度での到達予想時間、光での所要時間、最高速での所要時間。時間倍率をかけている時は「実時間で」何秒待つかも併記

## 探査機の旅

イベント一覧（K）の「探査機の旅」のページで探査機を選んで Enter を押すと、地球を出発してから目標に着くまでを、探査機のすぐ後ろから追います（地球から出発する軌跡のある 19 機と、はやぶさ2・OSIRIS-APEX の延長ミッション。延長ミッションは試料のカプセルを届けた地球スイングバイから、トリフネ・アポフィスまで）。

- 何もない巡航の間は時間を速く進め（ベピコロンボなら 1 秒で約 12 日、全行程で 15 分ほど）、出発・地球の重力圏の脱出・スイングバイ・小惑星や衛星への接近・到着では、時間を等倍まで落として説明を出します。スイングバイでは高度と太陽に対する速さの変化、到着では年数・スイングバイの回数・飛行距離も出します
- 巡航の間は、左下に探査機のこと（機体の特徴・目的・旅のエピソード）を 14 秒ずつ順に出します
- 右上の小さな全体図（太陽系を真上から見た図）に、通ってきた道（明るい線）・これから通る道（暗い線）・場面の場所・今の位置（緑の輪）を出します。惑星や小惑星の近くでは、そのあたりの拡大図に切り替わります（全体図と同じく太陽に対して止まった見方なので、探査機の進む向きは全体図と同じ。天体も図の中を動きます）。F3 で表示と非表示を切り替えます
- マウスのドラッグ・矢印キー・タッチのドラッグで見回せます（探査機は画面の同じ所に残り、操作をやめて 3 秒で自動の向きに戻ります）
- 画面下のタイムラインに場面が点で並びます。点をクリック・タップするとその場面へ、棒の途中ならその時刻へ移ります（点にマウスを乗せると見出しが出ます）。`[` `]` で旅の速さを「ゆっくり」（全行程で約 10 分）・「標準」（約 4 分）・「速い」（約 1 分）から選べます
- Enter で次の場面、Shift+Enter で前の場面、P で停止、Esc でやめます。目標に着くと完了です。まだ起きていない場面（計画上の軌道）には「（予定）」が付きます
- 小惑星（ガリレオのガスプラ・イダ、ルーシーのディンキネシュ・ドナルドジョハンソンと木星のトロヤ群の 5 つ）は、実際の軌跡の距離で近づき、点にしか見えない大きさなので自動でズームします
- 衛星への接近の距離は、シミュレータの衛星の位置（実際とずれることがあります）での値です
- **リンクで開く**: ブラウザ版の URL に `?voyage=探査機の英語名` を付けると、その旅を出発から始めます。`&scene=arrive` で到着の直前から、`&scene=番号` でその場面から、`&leg=2` で延長ミッションの旅を。旅の途中で F2 を押すと、その場面のリンクをコピーします。例: [ベピコロンボの水星到着](https://hubstacksea.github.io/Solar-System-Simulator/?voyage=BepiColombo&scene=arrive)、[ボイジャー1号の旅](https://hubstacksea.github.io/Solar-System-Simulator/?voyage=Voyager%201)。PC 版は `--share "?voyage=BepiColombo&scene=arrive"` で開けます

## アポロ計画

イベント一覧（K）の「アポロ計画」のページで飛行を選んで Enter を押すと、打ち上げから月への到着・着陸・帰還・着水までを、宇宙船のすぐそばから年代順に追えます（月へ向かった 8・10〜17 号。13 号は酸素タンクの爆発で着陸を中止し、月の裏を回って帰還）。

- 探査機の旅と同じ見せ方で、できごと（各段の切り離し、月へ向かう噴射、月を回る軌道への噴射、着陸、月面での活動、離陸、ドッキング、大気圏突入、着水など）ごとに時間を等倍まで落として説明を出します。司令船と月着陸船が分かれている間は、場面に応じてどちらかを追います（月着陸船の上昇段の記録が終わった後は司令船）
- 機体の形は時刻に応じて変わります（サターン V の各段、司令・機械船と月着陸船、月面に残る下降段、パラシュートを開いた司令船）。つながっている間の月着陸船は司令船の先に描きます。月を回る軌道での切り離しと上昇段とのドッキングは、2 機を横から見る見方で、月着陸船がドッキングの口から離れて向きを変え、上昇段が近づいて並走し、向きを合わせて接触するまでを描きます（各号の記録の時刻と距離。見つからない値は手順の値）。第3段から離れて向きを変え、第3段に収まった月着陸船とドッキングして引き出すまでは、各号の記録の速さと時刻で第3段とアダプターの板も描きます。第1段・段間リング・第2段も、切り離すと逆噴射で減速して離れ、地球の重力で落ちていきます。右上の図は地球が中心で、月の近くでは月のまわりの拡大図になります（月から見た道なので、月を回る軌道はそのまま楕円に見えます）
- イベントを選ばなくても、日時がその飛行の間なら宇宙船は表示され、記録どおりに動きます（月面の下降段は離陸の後もずっと残ります）
- 噴射の間はエンジンから炎や噴流が出ます（サターン V の第 1 段は明るい炎、ほかのエンジンは真空の中でかすか）。主エンジンの噴射ではエンジンを推力の反対へ向け、月を回る軌道に入る時などの減速では後ろ向きに噴射します（噴射の前後 4 分で向きを変えます）。そのほかの間は先端を進む向きへ向けます。追っている機体の噴射の始めと終わりでは、時間を等倍まで落とします
- 軌道は NASA の飛行記録（Apollo by the Numbers と各号の Mission Report）にある時刻ごとの位置と速度から、地球・月・太陽の重力で計算してつないだものです（宇宙船そのものの軌道の暦は公開されていません）。記録の位置を通るように噴射の時刻で速度を合わせ、月の重力のむら（計算に入れていない）の分は区間全体で少しずつ埋めています。打ち上げは上昇の記録の点を通り、月面への降下と上昇は記録の時刻・高度・速さを通るようにつなぎ（降下の途中の目安は 11 号の記録）、大気圏突入は記録の最大加速度・パラシュートを開く時刻と場所に合うよう運動方程式で解いています
- **リンクで開く**: URL に `?apollo=11` を付けるとその飛行を打ち上げから、`&scene=番号` でその場面から始めます。PC 版は `--share "?apollo=11"`

## 仕組み

- **天体位置**: 水星〜海王星は惑星の位置の級数 VSOP87（Bretagnon & Francou 1988。約 5,700 項に間引いたもの）で計算します。JPL Horizons（DE441）との差は 1500〜2500 年で水星〜土星 1.5″ 以内・天王星と海王星 8″ 以内、紀元前 3000 年〜西暦 3000 年の全体で 4.4′ 以内です（遠い昔ほど VSOP87 そのものの誤差で大きくなります）。軌道の線は今の位置と速度から求めた楕円で、惑星をちょうど通ります。冥王星は JPL の平均軌道要素とその変化率からケプラー方程式で計算します。地球の自転の遅れ（ΔT。紀元前 500 年〜西暦 2150 年は NASA の日食表と同じ Espenak & Meeus の式、その外は Morrison & Stephenson 2004 の式。紀元前 500 年で約 4.8 時間）と地球の自転軸の歳差（IAU 1976）も入れています。月は Meeus『Astronomical Algorithms』47 章の式（ELP-2000/82 を縮めた周期項）に、JPL Horizons（DE441）の月の位置に合わせた長期の補正を足して、実際の位置と満ち欠けを再現します。月の向きは IAU の月の自転の式で、地球から見て経度方向に ±8°、緯度方向に ±7° ほど首を振り（秤動）、縁の向こう側も少し見えます。紀元前 763 年〜西暦 2950 年の日食は、NASA の日食表と時刻 4 分・食の中心 2° 以内で一致します（`tools/run_checks.py` で確かめています）。ほかの衛星は JPL の平均軌道要素の軌道面に円軌道で置き、公転の位置を JPL Horizons の 1980〜2070 年の位置に合わせてあります（多くは誤差 1° 以内、最大でも数度。ミマスはテティスとの共鳴による ±43° の揺れも再現）。木星の衛星の影が木星に落ちる時刻も実際とほぼ一致します
- **準惑星・小惑星・彗星**: ケレス・ベスタ・エリス・リュウグウ・ベンヌ・イトカワ・ディディモス（衛星ディモルフォス）・ハレー彗星・ヘール・ボップ彗星・百武彗星・チュリュモフ・ゲラシメンコ彗星。惑星と同じ形の軌道要素と変化率を、JPL Horizons の 1980〜2070 年の位置に合わせてあります（太陽から見た方向の誤差は最大 0.6°）。ただしリュウグウ（2012〜2024 年）とチュリュモフ・ゲラシメンコ彗星（2012〜2018 年）は、地球や木星への接近で軌道が変わるため、探査機が訪れた頃だけで合わせてあり（誤差は 0.9° と 0.07°）、離れた年ほどずれます。周期 3.3 年のエンケ彗星は、木星の摂動などで近日点の時刻が回ごとにずれてこの形では合わない（最大 20° 以上ずれる）ため入れていません。探査機が途中で近くを通った小惑星（ガスプラ・イダ・ディンキネシュ・ドナルドジョハンソン・エウリュバテス・ポリュメレ・レウクス・オルス・パトロクロス・トリフネ・アポフィス）も、探査機が通った頃の位置に合わせてあります（誤差 0.2° 以内）。大きさと自転周期は JPL Small-Body Database の値で、形はガスプラ・イダ・ドナルドジョハンソンが実際の形、ほかは球です。アポフィスは 2029 年 4 月 13 日に地球の中心から 3.8 万 km を通って軌道が変わるので、2024〜2060 年は JPL Horizons の軌跡で動きます
- **彗星の尾**: 太陽から 4 AU より内側でコマ（核を包む光）と尾が現れ、近いほど長く明るくなります（大彗星のヘール・ボップ彗星はより遠くから、より大きく）。青いイオンの尾は太陽と反対方向へまっすぐ、黄白色のダストの尾は公転の後ろ側へ曲がって伸びます。K キーの彗星のページから、ハレー彗星の 1986 年・2061 年の近日点、百武彗星が地球から 0.1 AU を通過した 1996 年 3 月 25 日などへワープできます
- **表面**: 木星は Cassini の全球図で、大赤斑は観測記録に合わせた今の位置（体系 II 経度。1962 年以降の記録と、それ以降の年 16° のずれ）に来るよう回ります。土星も Cassini の全球図（2011 年 8 月。北半球の大嵐の名残が見えます）で、両極と、環の影で写っていない赤道から南緯 17° までは手続き的な雲です。水星・火星・ケレス・ベスタ・冥王星と、イオ・エウロパ・ガニメデ・カリスト・ミマス・エンケラドゥス・テティス・ディオネ・レア・イアペトゥス・ミランダ・アリエル・ウンブリエル・チタニア・オベロン・トリトン・カロンは、探査機の画像による実際の地図を貼っています（オリンポス山やマリネリス峡谷、冥王星のハート、エンケラドゥスの縞などが本当の位置に見えます）。火星は MOLA の標高で起伏の陰影も付きます。水星・火星・ケレス・ベスタ・冥王星は IAU の本初子午線に合わせて自転し、衛星はいつも同じ面を母惑星に向けます。撮影されていない範囲（天王星の衛星の北半球、冥王星・トリトン・カロンの一部など）と、地図より細かい模様・起伏は手続き的に補います。イアペトゥスは地図の明暗がならされているので、明るい半球と暗い半球は手続き的に塗り分けます。天王星・海王星・金星は、自由に再配布できる全球図が見つからない（天王星と金星は目に見える光ではほとんど模様もない）ため、手続き的な模様のままです。そのほかの天体はシェーダで手続き的に生成。近づくほど細かい模様と起伏が現れ、地表付近でも模様が潰れません
- **地球**: NASA の実データで、大陸・海岸線・標高（起伏の陰影）・水深（浅瀬の色）・海氷・夜の街明かりを再現（約 10 km 解像度。それより細かい部分は手続き的に補完）。自転の向きはグリニッジ恒星時に合わせてあるので、PC の時刻で実際に昼の地域が明るく、夜の地域に街明かりが見えます。地表の色は Blue Marble の 12 か月分から日付に合わせて変わり（冬の雪、雨季の緑など）、雲は NASA の雲の全球画像（ある日の分布）に細かい筋を足して描きます
- **月**: NASA の実データ（LRO の色と LOLA 標高、約 3〜5 km 解像度）。海・クレーター・光条が実際の位置にあり、それより細かいクレーターは手続き的に補完
- **音楽**: 一番近い天体の曲を流します。惑星はホルスト《惑星》（衛星の近くではその母惑星の曲）、太陽はグリーグ「朝」、地球はベートーヴェン「田園」第1楽章、月はドビュッシー「月の光」。近いほど大きく、離れると小さくなり、影響圏の外（太陽は 1 AU）で消えます。曲が変わる時はフェードで切り替わり、戻ってくると続きから流れます。冥王星の近くでは流れません（冥王星の曲は後年の別の作曲者の作品で著作権が残っているため）。準惑星・小惑星・彗星の近くでも流れません
- **地球のまわりの宇宙機**: 国際宇宙ステーション（ISS）とハッブル宇宙望遠鏡は CelesTrak の軌道要素（TLE、2026 年 10 月 28 日）から、地球の扁平による軌道面の回転も入れて位置を計算します（Horizons との差は約 35 km）。元期から離れるほどずれ、ISS は数日で数百 km、数か月で軌道上の位置が分からなくなります。ジェイムズ・ウェッブ宇宙望遠鏡（JWST）は JPL Horizons の軌跡で、地球から 150 万 km の L2 点のまわりを回ります（2031 年 10 月まで）。どれも Tab キーで選んで G キーで近くへワープできます
- **重力モード**: 設定画面か R キーで切り替えます。太陽・惑星・大きな衛星など質量 10²⁰ kg 以上の天体の重力を受けて飛び、ワープで着いた時と切り替えた時は今いる天体のまわりの円軌道に乗ります。天体の位置はフレームごとに更新し、その間は止まっているとして細かい刻みで計算します（刻みが足りないほど時間を速めた時は、自動で時間の進みを抑えます）
- **小惑星帯などの粒**: JPL の小天体データベースから、小惑星帯（明るい約 6 万個）・ヒルダ群などの外側の帯・地球近傍小惑星・木星のトロヤ群・ケンタウルス族・太陽系外縁天体の約 10 万個を、軌道要素から 2 体問題で動かして点で描きます（位置の計算と投影は GPU のシェーダで行います）。太陽系を遠くから見ると、小惑星帯の輪と、木星の前後 60° に集まるトロヤ群が見えます。軌道表示（O キー）と一緒に表示されます。最初の起動ではオフなので、見る時は設定画面（F10）でオンにしてください
- **探査機**: ボイジャー1号・2号、パイオニア10号・11号、ガリレオ、カッシーニ、ニュー・ホライズンズ、パーカー・ソーラー・プローブ、ジュノー、ロゼッタ、はやぶさ2、オシリス・レックス、DART が、JPL Horizons の記録どおりの経路を飛びます（打ち上げから運用終了まで。太陽系を脱出する機体はデータの終わり（2050〜2100 年）の後も直進）。惑星の影響圏の中では惑星からの相対位置で動くので、木星や海王星へのフライバイは実際の距離・向き・時刻で起こります（衛星への接近は、衛星の位置の誤差で数千 km ずれることがあります）。ロゼッタはチュリュモフ・ゲラシメンコ彗星を周回して 2016 年 9 月 30 日に核へ降下し、ジュノーは 2016 年 7 月 5 日から木星を周回します（2026 年 9 月より後は計画上の予測で、データは 2028 年 9 月まで）。はやぶさ2 のリュウグウ滞在中（2018 年 6 月 27 日〜2019 年 11 月 13 日）は、Horizons の機体とリュウグウの軌道が別々の解で数 km しか離れない値になるため、基本の待機位置（リュウグウの地球側 20 km、ホームポジション）に置いています。軌跡は O キーの軌道表示と一緒に表示され、通ってきた部分が明るく描かれます。機体は探査機ごとの簡易モデルで（ボイジャー・パイオニア・ガリレオ・カッシーニ・ニュー・ホライズンズ・パーカー・ジュノー・ロゼッタ・はやぶさ2）、高利得アンテナを地球へ向けます（パーカーは耐熱シールドを太陽へ）。カッシーニは 2004 年 12 月 25 日までホイヘンス・プローブを、ガリレオは 1995 年 7 月 13 日まで大気圏突入機を抱えています。マーカーは L キーの衛星マーカーと一緒に切り替わります。オシリス・レックスはベンヌに 2018 年 12 月から 2021 年 5 月まで滞在して試料を持ち帰り、DART は 2022 年 9 月 26 日にディモルフォスに衝突します（K キーの一覧とツアーから衝突の 1 分前へワープできます）。初代はやぶさは、イトカワ到着までと帰路の軌道データが公開されていないため入れていません。運用中の探査機として、ベピコロンボ（6 回の水星フライバイの後、2026 年 11 月に水星周回軌道へ）・JUICE（2031 年 7 月の木星到着の直前まで）・エウロパ・クリッパー（2030 年 4 月に木星周回軌道へ、2034 年 9 月まで）・ルーシー（木星のトロヤ群へ、2033 年 4 月まで）・サイキ（2029 年 2 月まで）・ヘラ（ESA。2026 年 10 月にディディモスへ到着、11 月 4 日まで）も、Horizons の計画上の軌道で飛びます（予定が変わると実際とずれます）。Horizons の時刻は力学時なので、世界時に直して使います
- **歴史上の天文現象**: イベント一覧の 4 ページ目に 18 件あります。日食・月食（アッシリアの日食 紀元前 763 年、タレスの日食 紀元前 585 年、水島の戦いの金環日食 1183 年、コロンブスの月食 1504 年、エディントンの日食観測 1919 年、21 世紀最長の皆既日食 2009 年）は、史実の場所の地上の、その場所で食が最も深い時刻へ移ります。超新星（1006 年、かに星雲のもとになった 1054 年、ティコの 1572 年、ケプラーの 1604 年）は、その時期だけ空に記録どおりの明るさで光り（明るさの変化は目安）、記録した場所の夜空へ移ります。ハレー彗星の回帰（紀元前 240 年の『史記』、1066 年のバイユーのタペストリー、1301 年のジョットの絵）、金星の太陽面通過（1639 年のホロックス、1769 年のクック、1882 年）、シューメーカー・レビー第 9 彗星の木星衝突（1994 年）、ガリレオが木星の衛星を見つけた夜（1610 年 1 月 7 日、パドヴァ。望遠鏡のような視野 0.5° で、記録どおり東に 2 つ・西に 1 つ並ぶ）もあります。木星には、JPL Horizons の 20 個の破片の軌道から求めた衝突の時刻と場所に、黒い衝突痕が現れて数か月かけて薄れます（大きさと薄れ方は目安）
- **太陽の黒点の活動周期**: 黒点の数と現れる緯度が、約 11 年の活動周期に合わせて変わります（周期の初めは緯度 30° 近く、終わりは 8° 近く）。周期の始まりの年は観測による第 1〜25 周期の極小の年で、黒点の量は平均的な周期の形の目安です。マウンダー極小期（1645〜1715 年）にはほとんど黒点がなく、ダルトン極小期（1798〜1823 年）は少なめです
- **ハレー彗星の昔の回帰**: 1948 年より前は、JPL Horizons の回帰ごとの軌道（紀元前 240 年〜1910 年の 30 回）で動きます
- **連星の近星点**: イベント一覧の「彗星・連星」に、ケンタウルス座アルファ星・シリウス・ルーマン 16・くじら座 BL 星と UV 星の連星が最も近づく時刻（例: ケンタウルス座アルファ星は 2035 年 4 月 30 日に 11.2 AU）があり、選ぶと 2 つの星を横から見る場所へワープします
- **天文イベント**: K キーの一覧から、日食（食の中心の上空 12,000 km。皆既・金環は食の中心の地上から見る場面も選べ、皆既の間はコロナが広がり、空が暗くなって星が見えます）・月食（月の横）・木星面の影の通過（影の真上）・衝の惑星（地球側から、満月のように全面が照らされた姿）へ、その日時に合わせてワープできます。日時は簡易計算なので、実際との差は日食・月食で 15 分程度、日食の中心位置で数百 km 程度です。太陽面通過は地球と惑星を結ぶ線の上（地球から見た時と同じ位置関係で、惑星が大きく見える所）から、惑星どうしの接近は地球のすぐ外から、それぞれズームした視野で見ます（右クリック・移動で元の視野へ）。木星の衛星どうしの食は、衛星の位置の誤差（衛星の大きさより大きい）で正しく求められないため入れていません
- **影**: 日食（地表に落ちる月の影）・月食（赤銅色の月）・木星の衛星の影・土星の環の影を、太陽の大きさを考えた本影と半影で描きます
- **地上から空を見る**: 地表近く（高度 100 km 以下）で止まっている時は、天体の自転と一緒に回ります。検索の「地上」から場所を選ぶと、その地上から赤道側の空を見上げ（月面では地球が、太陽系の外の惑星ではその恒星が空にあればそれを見る）、時間を進めると星や惑星が日周運動で動いていきます（昼は青空で星が隠れるので、夜の時刻を Y キーで指定するか時間を進めてください）。地表（高度 2 km 以下、半径 100 km 以上の天体）にいる間は、地平線と東西南北の方位を描き、左下にその場所・時刻と、ターゲットの高度・方位（16 方位）、次の出・南中・入りの時刻（地球は大気の屈折を入れて、月面は月の 1 日分）を出します。時刻は、検索で選んだ地球の都市ではその標準時（夏時間は考えない）、ほかは UTC です
- **流星群**: しぶんぎ座・4 月こと座・みずがめ座η・ペルセウス座・オリオン座・しし座・ふたご座の 7 つの流星群を、極大の太陽黄経・放射点・ZHR（国際流星機構の値）で入れています。地球の地上で夜空を見ていると、活動している流星群の放射点から流れ星が流れます（1 時間あたり ZHR × 放射点の高さ。散在流星も 1 時間に 6 個。時間を進めると増え、実時間 1 秒に 4 個まで）。K キーの一覧（天文）に極大日が並び、選ぶと東京の地上から、極大の前後で一番よく見える夜に放射点の方角を見上げます
- **金星とタイタン**: どちらも厚い雲ともやに覆われた姿で描きます。金星の雲は、自転（243 日）よりずっと速い約 4 日で一周する流れ（超回転）で動き、タイタンには縁の外側に青く見える上空のもやの層（地表から約 500 km）を加えています
- **大きさ**: 赤道半径と扁平率（木星・土星はつぶれた形）、土星の環は Voyager 2 の恒星掩蔽観測による不透明度の分布（半径 10 km ごと）で、D 環〜F 環、カッシーニの間隙やエンケの間隙が実際の位置と濃さで見え、斜めから見るほど不透明になります。天王星（細い 10 本の環。自転軸と一緒に横倒し）・海王星（ガレ・ルヴェリエ・ラッセル・アラゴ・アダムズ環と、アダムズ環の 5 つの弧）・木星（ハロー・主環・2 つのゴサマー環）の環も、NASA の資料の半径・幅・光学的厚さで描きます。これらはとても暗く薄いので、見えるように濃さを強調し、遠くで画素より細くなる天王星・海王星の環は線として残るように描きます（海王星の弧の位置は目安）。リュウグウ（そろばん玉形）・チュリュモフ・ゲラシメンコ彗星（2 つの塊がくびれでつながった形）・ベンヌ・イトカワ（ラッコ形）・ディディモスとディモルフォス・フォボスは探査機の観測による実際の形で、自転します。ディモルフォスは DART の衝突（2022 年 9 月 26 日）で公転周期が 11.92 時間から 11.37 時間に縮むところまで再現します
- **基準系**: 自機は「影響圏（SOI）」に入っている天体と一緒に移動します。地球近くでは自動車の速度でも地球に置いていかれません。Shift+F（または設定画面）で「自機に固定」にすると、どの天体とも一緒に動かず太陽に対してその場にとどまり、地球が秒速 30 km で去っていく様子や、衛星が目の前を通り過ぎる様子を見られます（重力モードでは実際の動きは変わらず、速度が太陽に対する値になります）。ワープ・地上へ移る・イベントへ移る・自動操縦を始めると自動に戻ります
- **精度対策**: 位置は double で保持し、カメラ相対で描画。天体ごとにスケールを変えて個別の near/far で描くため、30 m の自機から 45 億 km 先の海王星まで同時に描画できます
- **最低高度**: 浮動小数点精度の都合で、天体半径の 1/100,000（最低 30 m）より下には降りられません（地球で約 64 m）
- 物理演算（重力など）は行いません。自機は機首方向へ進むアーケード式です

## 地球と月のデータ・星空・音楽

`assets/` の画像は `tools/make_earth_assets.py` と `tools/make_moon_assets.py` で NASA・NOAA のデータから作り、ビルド時に実行ファイルへ埋め込みます（実行時にファイルは不要）。

- 地表の色: NASA Earth Observatory, Blue Marble: Next Generation（2004年4月）
- 標高・水深: NOAA NCEI, ETOPO 2022 Global Relief Model（60 秒角・氷床表面、5 分角に間引いて使用）
- 夜の街明かり: NASA Earth Observatory, Black Marble 2016
- 月の色・標高: NASA's Scientific Visualization Studio, CGI Moon Kit（LROC WAC / LOLA）
- 惑星・衛星の地図: USGS Astrogeology Science Center の天体地図サービス（[planetarymaps.usgs.gov](https://planetarymaps.usgs.gov/)）の全球モザイク（木星は Cassini の PIA07782（NASA/JPL/Space Science Institute）、MESSENGER、Viking MDIM 2.1（NASA Ames による着色）、Dawn、Galileo / Voyager、Cassini、Voyager 2、New Horizons）と、火星の標高 NASA PDS MGS MOLA MEGDR。土星は NASA PDS 大気ノードの [Cassini ISS の全球図](https://doi.org/10.17189/rkkb-6y30)（2011 年 8 月 11 日の赤・緑・青のフィルター）。天王星の 5 衛星は、JPL の [Solar System Simulator](https://space.jpl.nasa.gov/tmaps/uranus.html) が配っている USGS の全球図（Voyager 2。撮影されたのは南半球だけ。Courtesy NASA/JPL-Caltech、[JPL の画像利用規定](https://www.jpl.nasa.gov/jpl-image-use-policy)）。`tools/make_planet_maps.py` で取得・変換（Pillow と NumPy が必要、約 105 MB をダウンロード）。木星の大赤斑の経度は [Project Pluto](https://www.projectpluto.com/grs_lon.txt) がまとめた観測値（1964 年以降は JUPOS）
- ISS とハッブル宇宙望遠鏡の軌道要素: [CelesTrak](https://celestrak.org/)（`tools/fetch_tle.py` で取得）。JWST の軌跡: NASA/JPL Horizons
- 小惑星などの軌道要素: JPL Small-Body Database（`tools/make_asteroid_assets.py` で取得・変換、NumPy が必要、約 20 MB をダウンロード）
- 探査機の軌跡: NASA/JPL Horizons（`tools/make_probe_assets.py` で取得・間引き。ロゼッタは ESA、はやぶさ2 は JAXA の軌道決定による）
- アポロ計画の宇宙船の軌跡: NASA の飛行記録（R. W. Orloff, *Apollo by the Numbers*, NASA SP-2000-4029 と各号の Mission Report）の位置と速度から `tools/make_apollo_assets.py` で計算（月と太陽の位置は JPL Horizons）
- 星空: ヒッパルコス星表（ESA）の恒星と、88 星座の星座線・名前（日本語・学名）・恒星の固有名。星の距離と固有運動はヒッパルコス新整約（van Leeuwen 2007）の年周視差と固有運動（ESA Gaia アーカイブから取得）。[d3-celestial](https://github.com/ofrohn/d3-celestial)（Olaf Frohn, BSD 3-Clause）のデータを `tools/make_sky_assets.py` で変換
- 近くの恒星: Gaia DR3（ESA/Gaia/DPAC）・ヒッパルコス新整約（van Leeuwen 2007）の位置天文データと、連星の軌道・質量の論文（Akeson et al. 2021、Bond et al. 2017、Kervella et al. 2016、Lazorenko & Sahlmann 2018）など。出典の一覧と値は `tools/make_nearby_stars.py`（`src/nearby_stars.h` を作る）。惑星: NASA Exoplanet Archive（Suárez Mascareño et al. 2025、Basant et al. 2025、Hurt et al. 2022、Thompson et al. 2025）
- 彗星・小惑星の形: リュウグウは Watanabe et al. (2019) の形状モデル（出典 ISAS/JAXA、[JAXA DARTS](https://data.darts.isas.jaxa.jp/pub/hayabusa2/paper/Watanabe_2019/)）、チュリュモフ・ゲラシメンコ彗星は ESA の NAVCAM による形状モデル MTP019 の低解像度版（ESA/Rosetta/NAVCAM – CC BY-SA IGO 3.0、NASA PDS Small Bodies Node より取得）。ベンヌ（OSIRIS-REx）・イトカワ（Gaskell et al., Hayabusa AMICA）・ディディモスとディモルフォス（DART）・フォボス（Gaskell）・ドナルドジョハンソン（Lucy、DLR のチーム）は NASA NAIF の SPICE 形状データ（DSK）。ダイモスは Thomas の形状モデル（Viking Orbiter の撮影から。NASA PDS Small Bodies Node）。ガスプラ・イダ・ハレー彗星の核は Stooke の形状モデル（Galileo、ハレー彗星は Giotto・Vega の撮影から。ハレー彗星は指向の計算が Abergel。NASA PDS Small Bodies Node、パブリックドメイン。配布元が自動の取得を受け付けないので、ブラウザで取得して作業ディレクトリに置く）。`tools/make_shape_assets.py` で座標を 16 ビットに丸め（フォボスは間引き）、表面までの半径の表を加えて変換（NumPy と spiceypy が必要）
- 土星の環: NASA PDS Ring-Moon Systems Node の Voyager 2 光偏光計によるさそり座デルタ星の掩蔽観測（VG_2801）。`tools/make_ring_assets.py` で変換
- 天王星・海王星・木星の環: NASA NSSDCA の Uranian / Neptunian / Jovian Rings Fact Sheet の半径・幅・光学的厚さ（`src/app/bodies.h` の `RingSets`）
- 地球の季節と雲: NASA Earth Observatory, Blue Marble: Next Generation の 2004 年 1〜12 月と、Blue Marble の雲の全球画像。`tools/make_earth_season_assets.py` で変換（約 150 MB をダウンロード）
- 惑星の位置: VSOP87A（Bureau des Longitudes）。係数は Greg Miller の [VSOP87-Multilang](https://github.com/gmiller123456/vsop87-multilang)（パブリックドメイン）から `tools/make_vsop87.py` で間引いて作成
- 天の川: NASA/Goddard Space Flight Center Scientific Visualization Studio, [Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851/)（明るい星を除いた天の川の光。Gaia DR2: ESA/Gaia/DPAC）を `tools/make_milkyway_asset.py` で変換（Pillow と NumPy が必要、約 35 MB をダウンロード）
- 音楽（ホルスト《惑星》）: 水星は米空軍軍楽隊（2013 年、編曲も同軍楽隊）、ほかの 6 曲はホルスト指揮ロンドン交響楽団の 1922〜23 年録音（Columbia）。パブリックドメイン

いずれも商用を含め自由に使用・再配布できるデータです（詳細は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)）。作り直す場合は `python3 tools/make_earth_assets.py <作業フォルダ>`（約 50 MB をダウンロード）と `python3 tools/make_moon_assets.py <作業フォルダ>`（約 45 MB）。どちらも Pillow が必要です。

## 表示言語（日本語 / English）

- **J キー**でいつでも切り替えられます。選んだ言語は `solar_voyager.cfg` に保存され、次回起動時も使われます
- `solar_voyager.cfg` には言語・画質・効果音・星座の表示・ブックマークを保存します。場所は実行ファイルと同じフォルダ（書き込めない場合、たとえば .deb / .rpm でインストールした時は `~/.config/solar_voyager/solar_voyager.cfg`。macOS は `~/Library/Application Support/SolarSystemVoyager/`）
- 起動時に指定する場合: `solar_voyager --lang en`（または `ja`）。優先順位は「起動オプション > 保存された設定 > 日本語」です

日本語表示には OS の日本語フォント（Windows: メイリオ / 游ゴシック / MS ゴシック、macOS: ヒラギノ角ゴシック、Linux: Noto Sans CJK / IPA など）を自動で探して使います。
見つからない場合は英語表示に固定されます。`assets/font.ttf` を置くとそれを優先します。
